![Broccoli 智能云端编程管家](https://showhntoday.com/images/47865642.png)

**URL：** [https://github.com/besimple-oss/broccoli](https://github.com/besimple-oss/broccoli)

**作者：** yzhong94

**描述：**
Broccoli 是一个开源的智能编程助手，它能将项目管理工具（如 Linear）中的编码任务，在独立的云端环境中执行，并自动生成可供人工审查的代码提交请求（PR）。它解决了开发团队在同时处理多个编码任务时，频繁切换上下文、管理本地开发环境以及因任务中断导致效率低下的问题。

**如何使用：**
开发者可以将 Broccoli 集成到现有的开发流程中。首先，将项目管理工具（例如 Linear）与 Broccoli 连接，配置好代码仓库（例如 GitHub）和云端运行环境（例如 GCP 或 Blaxel）。当有新的编码任务（如添加新功能、修复 bug、重构代码）在 Linear 中创建并分配时，Broccoli 会自动触发。它会从 Linear 获取任务的详细信息，然后在云端沙箱中完成编码、测试等步骤，最后在 GitHub 上创建一个 PR。开发者只需定期检查 GitHub 上的 PR 即可。

### 5.XTrace: 隐私至上的加密向量数据库

![XTrace: 隐私至上的加密向量数据库](https://showhntoday.com/images/47867151.png)

**URL：** [https://github.com/XTraceAI/xtrace-sdk](https://github.com/XTraceAI/xtrace-sdk)

**作者：** TristanX

**描述：**
XTrace 是一个从零开始构建的私有向量数据库，它可以在加密的向量数据上进行相似性搜索。最核心的创新在于，服务器端永远不会看到您的明文嵌入（embeddings）或原始文档。这解决了当前所有向量数据库在处理敏感数据（如医疗、法律、金融信息）时，其向量嵌入可能被反向解析暴露风险的问题。XTrace 在您的本地机器上完成所有加密，使用 Paillier 同态加密处理向量，AES-256 处理文本，服务器端仅存储和搜索密文，您的密钥绝不离开您的环境。

**如何使用：**
开发者可以将 XTrace 集成到你的应用程序中，特别是那些需要处理敏感数据的场景，比如构建一个基于患者病历的智能问诊系统，或者一个包含机密合同的法律文件搜索工具。你首先需要在你的本地环境或受控的服务器上设置 XTrace。然后，当你需要存储数据时，使用 XTrace 提供的 SDK（一套方便你调用的工具）先在你的本地对数据（文本和生成的向量嵌入）进行加密。加密后的数据会被发送到 XTrace 数据库进行存储。当你需要进行搜索时，同样是在本地进行查询的加密，然后发送给 XTrace 进行密文搜索。XTrace 会返回最相似的密文结果，你再用你的密钥在本地解密，就能得到所需信息。XTrace 支持标准的 API 调用，可以方便地接入到各种后端服务或AI流程中（比如 RAG - Retrieval Augmented Generation，一种让大型语言模型能参考外部知识的AI技术）。
