![线缆智鉴](https://showhntoday.com/images/47972511.png)

**URL：** [https://github.com/darrylmorley/whatcable](https://github.com/darrylmorley/whatcable)

**作者：** sleepingNomad

**描述：**
线缆智鉴是一款macOS菜单栏小工具，它能够读取Mac电脑连接的USB-C线缆的真实数据，并用通俗易懂的语言告诉你这条线缆的充电功率、数据传输速度、是否支持高分辨率显示以及是否支持Thunderbolt等高级功能。这解决了USB-C线缆外观相似但功能差异巨大的痛点，让你不再为选择合适的线缆而烦恼。

**作者：** keepamovin

**描述：**
GhostBox 是一个命令行工具，它能让你轻松地从 GitHub Actions 的免费计算资源中“借用”一个临时的、用完即丢的虚拟机（简称“一次性小机器”）。它解决了开发者在测试不同操作系统下的代码构建、进行快速实验或临时开发任务时，需要配置和维护独立环境的痛点。通过将 GitHub Actions 的强大能力转化为一个方便的 CLI 工具，GhostBox 极大地降低了临时开发和测试的门槛，让开发者能更专注于代码本身。

**如何使用：**
开发者可以通过安装 GhostBox 的命令行工具，并在 GitHub 上配置相应的 Secrets（用于访问 GitHub Actions API）和 Actions 工作流。随后，只需在终端运行简单的 GhostBox 命令，就可以指定操作系统、所需的软件环境等，GhostBox 就会在后台启动一个 GitHub Actions 工作流，为你准备好一个临时的虚拟机。你可以通过 SSH 等方式连接到这台虚拟机，进行你的开发、测试或实验。完成工作后，这个虚拟机和它上面的所有环境都会被自动销毁，不会占用你的资源。这种方式非常适合进行跨平台构建测试，例如你想知道你的代码在 Ubuntu、macOS 和 Windows 上编译效果如何，就可以通过 GhostBox 快速启动这几种环境进行测试，无需在本地逐一配置。

### 5.Perfect Bluetooth MIDI Bridge

**作者：** mayerwin

**描述：**

**如何使用：**
